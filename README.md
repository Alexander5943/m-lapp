# Mål.

En enkel app där du skriver ner dina mål för varje år som en checklista.

- Varje lista har ett år som rubrik (t.ex. 2027).
- Lägg till mål, bocka av dem och se hur långt du har kommit.
- Skapa nya listor och ta bort gamla.
- Allt sparas automatiskt på din enhet (localStorage).
- Fungerar offline och kan läggas till på hemskärmen.

## Lägg till på hemskärmen

**iPhone (Safari):** öppna sidan → Dela-knappen → *Lägg till på hemskärmen*.

**Android (Chrome):** öppna sidan → menyn ⋮ → *Lägg till på startskärmen* / *Installera app*.

## Publicera med GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, mapp `/ (root)` → Save.
